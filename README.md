## Реализованные механики

Сюжет: лесной тракт защищает поселение от трёх военачальников. 3 главы × 4 волны, краткие завязки и развязки глав, боссы на 4/8/12 волне. Победа даёт возможность продолжить ту же сборку в endless. Отдельный бесконечный режим доступен с начала: биомы чередуются, враги растут в силе, босс каждые 4 волны. Оценка длины кампании 10–18 минут — гипотеза, требуется человеческий плейтест.

Три стартовых шара: железный без занятого слота, ледяной с заморозкой, огненный с уроном по площади. 15 уникальных реликвий и 5 слотов. После каждой волны выбор из 3 ещё не взятых реликвий или 10 монет. При заполнении слотов можно заменить одну реликвию. Реликвии: огонь, лёд, молния, яд, мультишар, монеты за убийства, крит, комбо-урон, спасение залпа, размер/урон, лечение между волнами, пробитие брони, проценты, усиленный импульс и бонус против элит.

Сочетания: лёд + молния добавляют две цели; комбо повышает урон серии; крит усиливает исходный удар и масштабируемые от него огненный/электрический эффекты. Проценты вознаграждают сохранение запаса денег. Импульс — ограниченный ресурс волны: подбрасывает шар, замедляет и повреждает врагов. Мультишар теряет жизнь только после потери всех активных шаров.

Лавка: урон, сила запуска, лечение, максимальное здоровье. Цены повышаются после покупок. Выбор обычной следующей волны или элитного натиска (+25% HP, +12% скорости, +8 монет за победу). Пять обычных врагов: орк, бегун, щитоносец, громила, знаменосец-лекарь. Боссы призывают подмогу, шаман также лечит. Пропуск босса к воротам — поражение, его нельзя переждать.

Прогресс забега, полный мир, рекорды и победы сохраняются. При возвращении к активной волне требуется нажать «Продолжить бой».

## Графика и звук

По референсу сохранены компактные враги относительно узкой высокой арены. Яркая трава, ступенчатые грунтовые дорожки, объёмная сине-серая кладка, короткие флипперы, физические каменные направляющие. Три палитры: тракт, руины, вечерние ворота. Анимация шага, разная экипировка и размер врагов, HP боссов, тени, след шара, вспышки критов, электрические цепи, числовой урон, кольца импульса и лечения. Окружение кэшируется, не рисуется тысячами плиток каждый кадр.

Музыка — оригинальная тихая синтезируемая dungeon-synth последовательность с басовым слоем. Удары и игровые события синтезируются Web Audio. Оригинальное видео всё ещё не было доступно для сравнения звука; совпадение с ним не заявлено.

3. Страница издателя Peglin: https://blitworks.com/game/peglin/ — разнообразие шаров, врагов, реликвий и встреч как источник реиграбельности.
4. Яндекс, актуальная документация: https://yandex.ru/dev/games/doc/ru/concepts/requirements ; https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv ; https://yandex.com/dev/games/doc/en/sdk/sdk-events ; https://yandex.ru/dev/games/doc/ru/sdk/sdk-player . ## Платформа и монетизация

Без SDK игра полностью работоспособна, имитации рекламы нет. В ZIP SDK запрашивается по `/sdk.js`, инициализируется один раз. Язык SDK читается, текущий интерфейс RU с русским fallback. Полный EN-словарь ещё не реализован — это открытый пункт playbook, перед отправкой его нужно закрыть либо явно ограничить поддерживаемый язык в брифе/Консоли.

Пауза: отдельные причины user/platform/blur/hidden/ad, а также модальный экран. Симуляция и звук работают только при активном бое без блокировок. Удерживаемые кнопки сбрасываются, первый delta ограничен. Callback рекламы не снимает другие причины паузы.

AD_PLACEMENTS:
- `chapter_next`: только после нажатия перехода после 4-й/8-й волны; interstitial, внутренний cooldown 90 сек, не универсальное правило платформы. Отсутствие показа/ошибка не блокируют переход.
- `run_retry`: после нажатия нового забега на экране поражения/победы; тот же SDK interstitial и однократный переход.
- `camp_bonus`: добровольная кнопка «Посмотреть рекламу → +20 ◈ дополнительно» в лавке, один бонус за привал. Награда только onRewarded, повтор/поздний callback не даёт второй бонус. Бесплатный путь к следующей волне всегда рядом.
- Sticky отключён: игровому полю и touch-кнопкам нужна высота экрана. В Консоли не включать автоматический sticky без отдельного плейтеста.

Сохранение: локальный ключ `forest-pinball-v2`, schema version 2. Проверяются схема, типы и диапазоны; рендер-объекты не сохраняются. Локальная запись после значимых действий и каждые 5 сек боя. Cloud через Player после успешного чтения; записи сериализованы, объединяют последнее состояние, не чаще 10 сек, retry после ошибки через 15 сек. Подтверждённая рекламная награда сначала записывается локально. Если чтение cloud не удалось, неизвестное удалённое сохранение не перезаписывается. Выбор более свежего сохранения по updated — простая клиентская стратегия, не гарантия решения конфликтов часов разных устройств. Авторизация не навязывается. Инапов нет.

## QA и статус

Проверено автоматикой: 12 правил симуляции, UI-переходы, покупки, ограничение слотов, именно одна выдача награды при повторных/поздних callback, восстановление следующей волны, corrupt-save rejection, невозможность пропустить босса. Восемь seed-проверок первой волны. Один автоматический забег с удержанием флипперов и выбором покупок прошёл все 12 волн: это технический сценарий, не доказательство хорошего баланса для человека.

Проверено в браузере через доступный HTTPS-предпросмотр: запуск кампании, полёт шара, рендер врагов, переход первой волны в награду, получение мультибалла, покупка лечения (26→12 монет, 1→3 жизни), следующая волна. Визуально проверены desktop 1280×720, portrait 390×844 и landscape 844×390. Это браузерные размеры, не реальные iPhone/Android устройства. Тест интерфейса проведён до финальной настройки траекторий/HP; финальный код повторно проверяется автоматикой и базовым браузерным smoke.

Не проверено в реальном черновике: SDK Loading/Gameplay indicators, настоящие рекламные показы, cloud между устройствами, реальный iOS Safari, старые браузеры, запуск в мобильном приложении Яндекса. Рекламные callbacks проверены тестовым адаптером; наличие кода не равно реальному показу.

5. Сделать иконку, обложку, реальные скриншоты игры, описание, инструкцию и возрастную маркировку по фактическому контенту. Название в каталоге пока не проверено на уникальность.
6. Отдельно проверить Safari/iPhone, Chrome/Android, desktop и модерационный чек-лист из приложенного playbook. Эта сборка — проверяемый MVP, не заявление о готовности к отправке.

Финальный browser smoke: после последней настройки физики открыта финальная HTML-сборка, выбран отдельный бесконечный режим и начата первая волна в 390×844; поле и управление отрисованы. Прямое восстановление браузерным reload не прогонялось; восстановление сохранения проверено интеграционным UI-тестом с сериализованным миром.
